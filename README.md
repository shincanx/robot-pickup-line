Entry for the [make.fun bounty "The Robot Pickup Line Championship"](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) — the funniest one-line pickup line a robot could use, 200 characters or fewer.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
